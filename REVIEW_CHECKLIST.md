# Peer review checklist (12 points)

| # | Requirement | Where to check |
|---|---|---|
| 1 | Home wireframe JPG | `Wireframe_Home.jpg` |
| 2 | Onboarding on the first launch | `OnboardingView.swift` / first launch |
| 3 | Three onboarding pages and Next button | Press Next twice, then Get started |
| 4 | Home header, hero, menu breakdown, food menu list | Home screen |
| 5 | Profile contains onboarding data | Home → profile icon |
| 6 | Profile edits survive app restart | Change name → Save → quit → reopen |
| 7 | Log out clears profile and returns to onboarding | Profile → Log out and clear data |
| 8 | Stack navigation, Back button | Home → dish details or Profile → Back |
| 9 | Hero description and search bar | Home green hero section |
| 10 | Selectable categories | Home → Starters, Mains, Desserts |
| 11 | Menu item list | Home → dish cards; works offline |
| 12 | Improvement suggestions | Peer review comments |

For the first-launch test after a previous run, delete the app from the Simulator and reinstall, or log out from the Profile screen.

Suggested reviewer note: "The UI clearly separates the hero, categories, and menu items. The onboarding and profile flow is easy to follow. Future improvements could include a cart and online ordering."
